# Democrat – Unity Mobile\n\nThis is the active mobile 3D implementation of **Democrat – The Game**.\n\n## Current first-playtest target\n\n1. Unity opens the Democrat main scene automatically.\n2. The character creation screen asks for first and last name.\n3. The player enters the government building at the public entrance.\n4. A third-person mobile character is spawned.\n5. The player can move with the left touch area and rotate the camera with the right touch area.\n6. The government building is generated with a complete first architectural pass:\n   - entrance hall\n   - reception\n   - security\n   - information area\n   - cafeteria\n   - visitor lounge\n   - toilets and changing room\n   - plenary hall\n   - large, medium and small committee/session rooms\n   - conference room\n   - election hall\n   - faction rooms\n   - member and leadership offices\n   - meeting room\n   - press conference room\n   - TV studio\n   - interview area\n   - press workstations\n   - technical/security/storage/staff rooms\n   - emergency exits\n   - corridors and public circulation\n   - fictional exterior/city backdrop\n7. Rooms contain initial furniture and visual detail. Interaction systems are intentionally not active yet.\n8. A compact GTA-RP-style online counter is shown at the top right.\n9. A 10,000-player world-capacity profile is included as the target architecture. The current offline prototype does not yet connect real multiplayer servers.\n\n## Important\n\nThe 10,000-player target is an architectural requirement, not a claim that 10,000 real clients are currently connected. Actual large-scale multiplayer will be implemented separately with authoritative networking, interest management, instancing/sharding where needed, and server infrastructure.\n\nThe language/session system is deliberately postponed. Later, players will choose their language in the appropriate halls and see sessions in that language.\n\n## Build\n\nAn Editor setup script automatically creates the Democrat main scene and adds it to Build Settings when the project is opened in Unity.\n\nAn installable Android APK still has to be produced by a Unity build environment such as Unity Build Automation or a local Unity Editor.
